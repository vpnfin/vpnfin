# VPNFin

Independent, reader-supported VPN research: [vpnfin.com](https://vpnfin.com/)

We don't run our own speed or leak tests. We check what VPN providers claim against published security audits, renewal prices at checkout, company ownership records and each country's VPN laws, and we name the source and date behind every figure.

This repository will hold the open data behind our tables: VPN audits, renewal prices and ownership.
